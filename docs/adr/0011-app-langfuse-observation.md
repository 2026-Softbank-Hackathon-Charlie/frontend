# ADR 0011: 앱 범위 Langfuse LLM 관측

- 상태: 승인된 구현 범위, 운영 프로젝트 연결은 별도
- 날짜: 2026-11-08

## 맥락

앱 관측 대화상자는 HyperDX 로그만 읽었다. AI를 사용하는 앱의 generation 지연·토큰·비용은 로그 집계로 증명할 수 없다. 이 변경은 실제 출처를 구분해 완성도·클라우드 활용 평가와 실제 관측 시연에 기여한다.

## 결정

HyperDX 분석 옆에 Langfuse LLM 관측을 제공한다. 앱 범위 AI 호출의 실측 이력 또는 검증된 Langfuse generation이 있을 때 진입할 수 있다. 구성된 AI 주소만으로 사용을 확정하지 않는다. 출처 미연결·앱 범위 미설정·미관측·수집 오류·미지원은 구분한다. 다른 앱의 응답이나 잘못된 계약은 표시하지 않는다.

`GET /v1/apps/{app}/llm-observability?minutes=60`은 플랫폼 서버가 고정한 프로젝트와 generation metadata의 정확한 앱 이름으로 읽는다. 브라우저가 프로젝트·조회 URL·인증 정보를 정하지 않는다. 응답은 허용된 식별자, 모델, 시각, 지연, 토큰, USD 비용, 오류 수준만 포함하며 프롬프트·입출력·원본 metadata는 포함하지 않는다.

최근 최대 100개 generation **표본**만 표시한다. 전체 요청량이나 청구 집계가 아니다. 누락값은 null이며 UI에서는 미측정으로 표시한다. 표본 합계는 모든 구성 값이 있는 경우에만 산출한다. 지연은 표본 평균이다. 응답 수집 시각과 조회 구간을 표시하고, 갱신 오류로 남은 값은 마지막 수신 결과로 구분한다. 실제 서버가 생성한 안전한 trace 링크만 제공한다.

기존 OpenAPI 전체 재생성에는 무관한 App.resources 계약 변경이 섞여 있었다. `npm run gen:llm-api`는 공식 openapi-typescript로 정본의 신규 endpoint와 재귀 의존 schema만 추출해 `llm-schema.d.ts`를 생성한다. 기존 타입을 수작업으로 완화하지 않는다. AI 서비스 공통 계약은 기존 공식 생성 타입을 재사용한다.

## 검증과 한계

HTTP 계약 fixture로 앱 범위, 미래 시각, 잘못된 응답, nullable 값, 출처별 상태와 진입 조건, trace 링크를 검증한다. 실제 브라우저 도구가 없어 시각·브라우저 상호작용 검증은 별도다. Langfuse 4.75.0 Pod 실행 메타데이터는 확인했지만 실제 프로젝트 키·앱 generation을 조회하거나 키를 발급하지 않았다. 운영 연결에는 서버 전용 설정과 앱 generation metadata 계측이 필요하다. 품질·이전 승인 게이트의 증거로 이 표본을 사용하지 않는다.
